# FXB Performance

App personal (PWA para iPhone) que lee entrenamientos y recuperación (Garmin vía Intervals.icu, plan de TrainingPeaks),
calcula la nutrición diaria según la carga, registra comidas con foto o texto y analiza la forma física en lenguaje simple.

- Diseño: `docs/blueprint.html` · Decisiones: `docs/CONTEXTO.md` · Maquetas: `docs/maquetas/`
- Stack: Next.js 16 + Supabase + Vercel. Pruebas: `npm test`.
