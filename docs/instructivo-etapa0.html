FXB PERFORMANCE

Etapa 0: publicar la app

Son 3 partes y toman unos 25 minutos en total. Al final tendrás la app en tu iPhone con tu usuario. Las pantallas de Supabase y Vercel están en inglés: lo que ves en gris es el texto exacto del botón.

Parte 1 · Supabase ~10 min · la base de datos

  1. Entra a supabase.com/dashboard con la misma cuenta de la app de finanzas.

  2. Pulsa el botón verde New project. Si te pide organización, elige la misma de finanzas.

  3. Completa el formulario:

    • Project name: FXB Performance
    • Database Password: pulsa Generate a password, cópiala y guárdala en un lugar seguro. No se usa en el día a día, pero no se puede recuperar.
    • Region: East US (North Virginia)

    Pulsa Create new project y espera 1–2 minutos.

    Por qué esa región: es la más cercana a Ecuador y está en el mismo lugar que los servidores de Vercel, así la app responde más rápido.

  4. Cierra el registro público. Menú izquierdo: Authentication → Sign In / Providers. Apaga Allow new users to sign up y pulsa Save changes.

    Por qué: así nadie más puede crearse una cuenta en tu app. Tus datos de salud quedan solo para ti.

  5. Crea tu usuario. Authentication → Users → Add user → Create new user.

    • Email: tu correo.
    • Password: una clave que recuerdes. Con esta entras a la app.
    • Marca Auto Confirm User. Si no lo marcas, la app te rechaza.

    Pulsa Create user.

  6. Copia dos datos. Pulsa el botón Connect arriba en la página del proyecto, o ve a Project Settings → API Keys:

    • Project URL: se ve como https://abcdxyz.supabase.co
    • Publishable key: empieza con sb_publishable_. Si solo ves una que dice anon public, esa sirve igual.

    Pégalos en una nota temporal; los usas en la parte 2.

    No copies la secret key ni la service_role. Esas no van en Vercel por ahora.

Si Supabase dice que alcanzaste el límite de proyectos gratis, detente y avísame. El plan gratis permite 2 proyectos activos y uno ya es el de finanzas, así que este debería entrar justo.

Parte 2 · Vercel ~10 min · publicar la app

  1. Entra a vercel.com/new con la misma cuenta de la app de finanzas.

  2. En Import Git Repository busca App-Deporte-y-Alimentacion y pulsa Import.

    Si no aparece: pulsa Adjust GitHub App Permissions, agrega ese repositorio, guarda y vuelve.

  3. En Project Name escribe fxb-performance. Framework Preset debe decir Next.js (lo detecta solo). No toques nada más.

  4. Abre Environment Variables y agrega estas dos. Copia los nombres exactos, con mayúsculas y guiones bajos:

    KEYVALUE
    NEXT_PUBLIC_SUPABASE_URLtu Project URL
    NEXT_PUBLIC_SUPABASE_ANON_KEYtu Publishable key

  5. Pulsa Deploy. Tarda 1–2 minutos. Cuando aparezca la celebración, pulsa Continue to Dashboard.

    En Domains verás la dirección de tu app, algo como fxb-performance.vercel.app.

Parte 3 · En tu iPhone ~3 min

  1. Abre la dirección de tu app en Safari. La app de Chrome no permite instalarla.

  2. Entra con el correo y la clave del paso 5 de la parte 1.

  3. Debes ver Hola, Francisco y tres líneas con OK.

  4. Instálala: botón Compartir (el cuadrado con flecha) → Agregar a pantalla de inicio → Agregar. Aparece el ícono negro con FXB.

  5. Mándame la dirección de la app y una captura de la pantalla con los tres OK.

Listo eso, la etapa 0 queda cerrada y arranco la etapa 1: tu perfil y el cálculo de calorías y macros.

Si algo falla

  • El Deploy falla en Vercel: casi siempre es un nombre de variable mal escrito. Revisa la parte 2, paso 4, y pulsa Redeploy.
  • "Correo o clave incorrectos": revisa que marcaste Auto Confirm User en la parte 1, paso 5. Si no, borra el usuario y créalo de nuevo.
  • Una línea dice FALLA: mándame la captura.
  • Cualquier otra cosa: captura de lo que ves y te digo dónde tocar.
